# AdaptLearn AI

## Google Services Used

| Service | Purpose |
|---|---|
| Firebase Authentication | Google OAuth user sign-in |
| Cloud Firestore | User progress and lesson data storage |
| Firebase Analytics | User engagement and learning event tracking |
| Gemini API (via @google/generative-ai) | Adaptive lesson and quiz generation |
| Google Cloud Run | Containerized deployment |
| Cloud Logging | Structured GCP-compliant error and event logs |
